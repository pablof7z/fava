<decisions_made>

- **Sharing is a planner decision, not an owner decision.** The owner keyed
  demand on `(relay, filter)`, collapsing equivalent observations before the
  planner saw them. `GOALS:296` forbids erasing distinctions merely because
  filters are equal, and a merged filter equals none of its inputs, so the key
  could not represent the result. Refcount lives on the installed wire
  subscription, N-to-1 via attribution fan-out.
- **Grouping batches unsent demand only.** A sent subscription is never
  rewritten. nmp measured the alternative at 90% waste and 1-to-20 concurrent
  subscriptions after twenty growth steps.
- **Routers get engine access through a one-method trait**, refusing anything
  not Explicit or CacheOnly. Not the concrete `Fava`: that would confer
  `publish`, `close`, `reset`, create an `Arc` cycle leaking the engine, and tie
  third-party routers to one engine. The query must run the **exact same code
  path** as an application query — if it needs a branch, that is a finding.
- **WRITE-027 settled:** a healthy chain whose routers all *answer* absence
  settles terminal. A chain where a router *failed* must not.
- **No backfilled PLAN or SUMMARY for 07.3-07.6.** Markers written saying no
  verdict may cite them. 07.9 verifies against the corpus instead.
- **`ObserveError::Relay` is deleted, not reshaped.**

</decisions_made>
