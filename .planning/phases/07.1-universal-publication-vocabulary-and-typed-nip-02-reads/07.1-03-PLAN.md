## Trust Boundaries

| Boundary | Description |
|---|---|
| Caller predicate -> receipt stream | Application code evaluates changing durable facts and could otherwise wait forever. |
| Broadcast notification -> durable receipt | Notifications may duplicate, race, or lag and cannot be treated as the authoritative state. |
