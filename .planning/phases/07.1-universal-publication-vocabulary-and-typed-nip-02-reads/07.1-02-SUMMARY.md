## Decisions Made

- Signer scope stays concrete and edit-only: unsigned and pre-signed payloads use the payload-general relay scope or universal door, never a runtime signer contradiction.
- Caller route order is an owned neutral fact. Temporary membership state deduplicates exact relay identities, but sorted keyed maps only represent derived destination lanes.
- Invalid stored route shapes are refused independently of semantic custody, including terminal rows whose semantic edit ownership has already been released.
