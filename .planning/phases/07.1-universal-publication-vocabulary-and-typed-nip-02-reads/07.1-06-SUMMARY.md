## Decisions Made

- Used standard `ToString` call syntax plus upstream `PublicKey::parse` so `PublicKey`, `&str`, and `String` share one fallible function without approving a new public conversion noun.
- Kept relay input typed as `Option<RelayUrl>` per the README North Star; malformed persisted relay strings are refused by the private decoder before materialization.
- Reserved opcode 3 for metadata add. Opcodes 1 and 2 remain exactly the original 33-byte add/remove meanings; malformed or trailing bytes do not enter a compatibility branch.
- Preserved the first valid-key matching `p` row exactly, including relay, petname, and extra columns; only later valid-key matches are removed. Invalid-key rows and all nonmatching rows remain opaque preserved data.
