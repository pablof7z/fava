## Decisions Made

- `fava.publish(edit)` remains a typed `MissingAuthor` refusal; edit publication succeeds through `fava.by(author).publish(edit)` or a composed `to(...).by(...)` scope.
- `followers_of(subject)` is an ordinary exact-tag `Query`; only `follows_of(snapshot)` is a pure projection.
- Existing target metadata is authoritative: `follow_with` metadata is used only when appending a missing target.
- Follow keeps the first target row and removes target duplicates; unfollow removes every row with a parseable matching target. Foreign non-target rows and content remain byte/order preserving.
- The existing vocabulary registry already contained complete entries for the delivered publication and NIP-02 nouns; no new public symbol was added in this documentation plan.
