# Phase 07.1.1 — Revoked pattern map

The original map prescribed obsolete symbols and ownership. It is retained
only to make that revocation explicit and supplies no implementation guidance.

Current enforced patterns are:

- `fava-query` bounds query authors, ids, tag values, kinds, and relays and
  returns its own exact `QueryError`.
- `fava-write` independently bounds explicit publication input and returns its
  own exact `WriteIntentError`.
- `fava-state` does not own application relay selection.
- NIP-29 decoders are event-local and tolerant: unknown tags, unused extra
  values, repetitions, and malformed siblings do not erase valid entries.
- `EventCoordinate` owns coordinate-string parsing.
- README inventories are compiler-derived; inventory size is evidence, never
  a design target.

The approved `SimpleGroup` required-head and finite-`Vec` input shape and its
falsifiers are in `docs/issues/0023-simple-group-relay-input-boundary.md`.
Pablo's approved query-owned non-broadening tag-axis intersection is recorded
in `docs/issues/0024-query-tag-axis-composition.md`.
`Query::intersect_tag_values` keeps disjoint axes present-empty and returns
only the query owner's exact bounded-input refusal.
