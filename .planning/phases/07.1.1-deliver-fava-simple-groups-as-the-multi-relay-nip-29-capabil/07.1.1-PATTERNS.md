### Neutral Multi-Kind Query Prerequisite

Current `Query::kind` replaces the kind axis with one `BTreeSet` entry
(`crates/fava-query/src/selection.rs:29-34`). Group records need an ordinary
query spanning kinds 39000 through 39005. Add the smallest generic builder next
to the existing literal builders:

```rust
#[must_use]
pub fn kinds(mut self, kinds: impl IntoIterator<Item = Kind>) -> Self {
    self.selection.kinds = Some(kinds.into_iter().collect());
    self
}
```

The exact spelling is a vocabulary decision; behavior must mirror `authors`
and `ids`: absent means unconstrained, present empty matches nothing, order and
duplicates are identity-inert. Evidence belongs in
`fava-query/tests/query_identity.rs` and
`fava-query-standard/tests/source_merge.rs`, including empty, duplicate,
construction-order, and conjunction with exact `d`. No universal evaluator
kind logic changes should be needed because `matches_selection` already checks
set membership (`fava-query-standard/src/lib.rs:119-138`). Never add a
NIP-29-specific query builder or evaluator branch.

### Exact `h`/`d`/`p` Queries and Source Policy

Copy inert query construction from `crates/fava-nip02/src/query.rs:91-127` and
literal tag storage from `crates/fava-query/src/selection.rs:7-20,50-66`.

Content:

```rust
selection
    .tag_values(SingleLetterTag::LOWERCASE_H, [group.id().to_owned()])
    .from_relays(group.hosts().iter().cloned())?
```

Records:

```rust
Query::events()
    .kinds((39_000_u16..=39_005).map(Kind::from_u16))
    .tag_values(SingleLetterTag::LOWERCASE_D, [group.id().to_owned()])
    .only_from_relays(group.hosts().iter().cloned())?
```

`from_relays` asks exactly the hosts while retaining `AnyLocal`, including
accepted local writes (`fava-query/src/lib.rs:119-135`). `only_from_relays`
asks exactly them and requires actual relay evidence from the set
(`lib.rs:137-152`). Refuse a content selection already owning the `h` axis;
never silently union contradictory group context.

Discovery remains ordinary queries: kind 10009 plus authors for saved
groups/relays; exact kind 39001/39002 plus lowercase `p` for admin/member
evidence. Implement groups-saved-by as a bounded pure projection over a
supplied snapshot and group, not as new `ValueSet` infrastructure.

### Pure Per-Host Projection and Disagreement

`GroupSnapshot` is a bounded pure transform of `QuerySnapshot`
(`crates/fava-query/src/lib.rs:405-435`), never an observation. For each host:

1. select records with actual evidence for that host;
2. select the replacement winner per `(host, kind, d)`;
3. parse the winner into its typed per-host value;
4. calculate `*_differ()` across complete typed host values;
5. expose `at(host)` without a default/canonical host.

Copy the replacement comparator from
`fava-query-standard/src/lib.rs:147-150` or
`fava-nip65/src/lib.rs:105-110`. Never field-merge metadata. Aggregate
member/admin views only when each entry retains host attribution. Absence does
not prove negative membership/admin. A single-host `Group` is the only
fork-selection vocabulary.

Typed record parsing copies NIP-65's boundary validation/accessor/error style
and NIP-02's row-conservation rule: every relevant row becomes a valid typed
entry or typed evidence with source index/raw columns. Preserve `PinnedItem`
source order. Key saved groups by `(relay, group-id)` and retain every saving
author.

### Kind-Blind Preparation and Pre-Signed Validation

Copy the universal door from `crates/fava/src/publication.rs:143-171,227-273,
294-317`. Simple-groups exposes `group.hosts()`, prepares an ordinary
`UnsignedEvent`, or validates and returns an exact `Event`; the app supplies
the route:

```rust
let write = fava.to(group.hosts().iter().cloned())?.publish(payload)?;
```

Preparation inspects group context only, never an event-kind allowlist. An
unsigned author-bearing draft gets exactly one lowercase `h`. A pre-signed
event returns byte-for-byte unchanged only when it already has exactly one
matching `h` and no missing, duplicate, or contradictory group context.
`WriteIntent::presigned` remains downstream signature/id/size/expiry owner
(`crates/fava-write/src/lib.rs:104-126`). Protocol refusal occurs before
custody.

Management helpers build ordinary NIP-29 events. Do not implement the README's
metadata/pin rebase verbs as semantic edits: locked context makes ordinary
management commands author-bearing events; only kind 10009 saved lists use
`ReplaceableEventEdit`.

## Shared Patterns

### Validate Before Work

Construction, query-axis conflicts, event context, edit bytes, and route bounds
must refuse before custody/provider work. Causal negatives assert zero custody,
zero provider calls, and zero EVENT frames, not only an error value.

### Conserve Evidence

Preserve every actual relay contribution, every relevant row as typed value or
typed evidence, and every unknown saved-list row/content byte during edits.
Deduplicate identity facts, never authority facts.

### Evidence First

Add public behavior and owner tests before production; capture causal RED;
implement; run focused Cargo/Bazel; perform named deliberate break and restore
exact bytes. The two-relay public canary is an exit gate, not a substitute for
pure tests.

## Anti-Patterns and Ownership Boundaries

| Do Not | Correct Boundary |
|---|---|
| Add simple-groups imports or NIP-29 switches to universal crates | Optional application-selected protocol crate |
| Return app-facing `WriteIntent` or add group publication/receipt/observation/runtime types | Ordinary event/edit plus universal facade |
| Auto-route or omit a selected host | `fava.to(complete_hosts)` |
| Mutate/re-sign pre-signed events | Validate context; return unchanged |
| Restrict group publication by event kind | Kind-blind context preparation |
| Use `from_relays` for relay-authored records | `only_from_relays` with actual evidence |
| Use `only_from_relays` for ordinary content | `from_relays` preserves local writes |
| Re-dedup content or discard relay evidence | Standard evaluator/EventRecord |
| Field-merge metadata or choose a canonical host | Independent host winners/disagreement |
| Treat omitted member/admin rows as negative proof | Inclusion-only attributed evidence |
| Collapse saved groups by id | `(relay,id)` plus saving authors |
| Convert ordered pins to a set | Ordered bounded values |
| Add `ValueSet` for this phase | Query plus pure projection |
| Use semantic edits for metadata/pins | Ordinary management events; edit kind 10009 only |
| Rebuild saved lists from understood rows | Target-local lossless surgery |
| Reuse relay data dirs/ports or infer teardown | Two exact supervisors and PID/port facts |
| Retain raw seeds/private keys | Process memory, staged scan, quiet dispatch |
