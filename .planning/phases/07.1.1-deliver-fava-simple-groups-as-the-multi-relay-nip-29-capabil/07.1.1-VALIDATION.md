# Phase 07.1.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust built-in tests and doctests through Cargo 1.90; Python `unittest`; Bazel/rules_rust; controlled Croissant processes |
| **Config files** | `Cargo.toml`, crate `BUILD.bazel` files, `.bazelrc`, `apps/canary/Cargo.toml`, `apps/canary/scenarios.json` |
| **Quick run command** | `cargo test -p fava-simple-groups --all-targets` once the crate target exists |
| **Full suite command** | Commands under Full Phase Gate |
| **Estimated runtime** | Focused tests under 60 seconds; full workspace/Bazel/canary gate measured during execution |

## Sampling Rate

- **After every task commit:** Run the owning focused test, `cargo fmt --all -- --check`, and `git diff --check`; add vocabulary checks for every public/API or architecture task.
- **After every plan wave:** Run all affected crate targets, strict Clippy for touched crates, the matching Bazel targets, vocabulary checks, and line gates.
- **Before independent verification:** Run the complete Full Phase Gate from a committed tree and verify the fresh controlled two-relay pair.
- **Max feedback latency:** 60 seconds for focused local tests; longer build/process gates must retain bounded command and process deadlines.

## Causal RED → GREEN → Deliberate Breaks

| Area | Named break | Required failing evidence |
|------|-------------|---------------------------|
| Neutral multi-kind query | Retain only the first supplied kind | Query identity, local evaluation, and exact NIP-01 demand tests |
| Content source policy | Substitute `only_from_relays` | Accepted-local group content visibility test |
| Record source policy | Substitute `from_relays` | Write-store-only record exclusion test |
| Per-host projection | Merge one metadata field, choose one host, or drop one host attribution | Exact fork/disagreement/attribution test |
| Signed preparation | Rebuild the signed event or admit duplicate `h` context | Byte-identity and pre-custody zero-frame tests |
| Saved-list edit | Rebuild from typed rows and discard one unrelated tag/content byte | Exact conservation test |
| Architecture | Add a normal facade/provider dependency or universal NIP-29 branch | Architecture falsifier |
| Canary | Omit relay B handoff/evidence/teardown from the sealed manifest | Exact pair-verifier assertion |

For each behavior task: record the exact causal RED before production code, the GREEN result, the named deliberate-break RED, the pre-break file checksum, byte-exact restoration, and the restored GREEN result. Compilation-only failures do not prove runtime behavior unless the promise is itself compile-time.
