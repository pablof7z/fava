# Phase 07.1.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust built-in tests and doctests through Cargo 1.90; Python `unittest`; Bazel/rules_rust; controlled Croissant processes |
| **Config files** | `Cargo.toml`, crate `BUILD.bazel` files, `.bazelrc`, `apps/canary/Cargo.toml`, `apps/canary/scenarios.json` |
| **Quick run command** | `cargo test -p fava-simple-groups --all-targets` once the crate target exists |
| **Full suite command** | Commands under Full Phase Gate |
| **Estimated runtime** | Focused tests under 60 seconds; full workspace/Bazel/canary gate measured during execution |

## Sampling Rate

- **After every task commit:** Run the owning focused test, `cargo fmt --all -- --check`, and `git diff --check`; add vocabulary checks for every public/API or architecture task.
- **After every plan wave:** Run all affected crate targets, strict Clippy for touched crates, the matching Bazel targets, vocabulary checks, and line gates.
- **Before independent verification:** Run the complete Full Phase Gate from a committed tree and verify the fresh controlled two-relay pair.
- **Max feedback latency:** 60 seconds for focused local tests; longer build/process gates must retain bounded command and process deadlines.
