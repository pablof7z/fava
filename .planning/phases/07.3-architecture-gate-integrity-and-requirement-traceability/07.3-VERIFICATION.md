## SC1 - Vocabulary checker integrity: PASS WITH GAPS

### Verified clauses

**Policy-covered declarations at every visibility.** `tools/rust_declarations.py` is a real lexer,
not a line regex: it blanks comments, string literals, raw strings, and character literals, then
tracks brace nesting so associated items inside `impl` and `trait` blocks are not counted as
declarations. `tools/check_vocabulary.py:208` sets `internal = library and directory == "src"`, so
every nominal declaration in a `crates/*/src` library - `pub`, `pub(crate)`, `pub(super)`, private -
is collected. The run reports 101 `unapproved nominal vocabulary variant` entries, which is the
class the audit said the gate was structurally blind to (`vocab-gate-blind-to-nonpublic-nominals`).
Falsified positively: `tools/tests/test_vocabulary_check.py:35 test_rejects_unapproved_nominal_variants_at_every_visibility`,
`:87 test_rejects_a_single_word_internal_declaration`, `:99 test_rejects_a_single_word_homonym_of_a_term_owned_elsewhere`,
`:117 test_rejects_a_declaration_embedding_no_registered_noun`. All 33 tests pass.

**Never treats `.planning/**` prose as authority.** `tools/check_vocabulary.py:260` sets
`spec_root = root / "docs" / "spec"` and `:268` globs only that tree. Guarded by
`tools/tests/test_vocabulary_check.py:261 test_planning_records_are_not_vocabulary_authority` and
`:278 test_planning_records_cannot_satisfy_a_registered_specification_entry`.

**Verifies `spec_crates`/`spec_symbols` against reality.** `tools/check_vocabulary.py:414,416` emit
`specified architectural crate is not implemented` and `specified architectural symbol is not
implemented`. The run produces 21 and 14 respectively - `fava-auth`, `fava-ffi`, `fava-nip05`,
`fava-standard`, `fava-relay-lab`, five testkits, and so on. A missing owner crate is a failure,
not silence. Guarded by `:293 test_reports_a_specified_crate_with_no_implementation` and
`:321 test_reports_a_specified_symbol_with_no_implementation`.

**No silencing heuristic (active).** `is_structural_crate_metadata` (`:218-247`) survives from the
era when `.planning/**` was scanned: it suppresses crate-like tokens inside phase-slug metadata,
`/tmp/` paths, worktree path segments, and the checker's own diagnostic text. Verified empirically
that it silences nothing today - forcing it to return `False` and re-running `check()` yields the
identical 170 problems. It is dead weight, not an active silencer.

### Gap

`registered public symbol does not exist: fava_runtime::OperationGeneration` is a false positive.
The symbol is public in `fava_runtime` via `crates/fava-runtime/src/generation.rs:8`
(`pub use fava_query::OperationGeneration;`). The checker collects declarations only, so a
re-export is invisible in both directions: it produces this false positive, and symmetrically a
`pub use X as Y` synonym - which `AGENTS.md:56` classes as a vocabulary change - would pass
silently. No such alias exists in the tree today (`grep -rn "pub use .* as [A-Z]" crates/*/src/`
returns empty), so the false negative is latent, not live.

Seven `duplicate registered symbol` diagnostics come from genuine duplication in
`docs/internals/vocabulary.toml` (`fava_query::QueryBranchId` and `QueryBounds` listed twice inside
one term at :305-309; `RelaySourceState`, `RelayDeadline`, `RelayWithdrawal`, `AuthenticationState`,
`BoundedText` listed at both :310-314 and :363-371). The gate is right; the registry is sloppy.

### Note on scope, not a defect

The gate reports public types declared in `crates/*/tests/` (`fava::BlockingSigner`,
`fava::NoopTransport`, `fava::TestMaterializer`) and in downstream packages (`canary::Scenario`,
`external_semantic_capability_proof::Harness`), plus the three package names `canary`,
`external-semantic-capability-proof`, `fava-external-null-cache-proof`. This is a deliberate
policy choice, pinned by `tools/tests/test_vocabulary_check.py:221,236,249`, and it is broader than
the literal text of `AGENTS.md:55`. Recording it so the reviewer decides rather than discovers.

**Gate state:** `python3 tools/check_vocabulary.py` exits 1 with 170 problems. Red on purpose per
the workflow comment at `.github/workflows/architecture.yml:47-51`.

## SC2 - Requirement traceability: FAIL

### What was delivered

The matrix at `.planning/REQUIREMENTS.md:407-612` covers all 131 authoritative spec IDs. Verified
mechanically: extracting `^## [A-Z]+-[0-9]+[A-Z]?` from
`docs/spec/FULL_FAVA_REWRITE_SPEC_GOALS_AND_OBJECTIVES.md` and the row keys from the matrix yields
131 on both sides with an empty symmetric difference. The audit's finding that 113 spec IDs
appeared nowhere in `.planning/` is closed. The matrix is also unusually honest: it quotes both
wordings where a counterpart weakens its spec original, and it explicitly refuses to count an
Out-of-Scope table row as coverage.

### Why it fails

The criterion has two conjuncts and both are unmet.

**"preserves its full conjunction."** Status counts across the matrix: 68 `MAPPED`, 26 `WEAKENED`,
31 `UNMAPPED`, 6 `DEFERRED`. 57 of 131 spec IDs have no counterpart that preserves the conjunction.
`QUERY-001` - the query language itself, mandatory for v1 - is `UNMAPPED` with the note that
`nested`, `derived`, `union`, `intersection`, `difference`, and `projected` return zero hits
across all of `.planning/`. Traceability is achieved; conjunction preservation is not.

**"a mechanical check fails when a mapped requirement weakens or splits its authority."** No such
check exists. `tools/check_requirement_traceability.py` does not exist. Nothing in `tools/`,
`.github/`, or `crates/` reads `.planning/REQUIREMENTS.md` or the goals spec - verified by grepping
every `*.rs`, `*.py`, `*.yml`, and `*.toml` in the repository for either filename, which returns
empty. The document says so itself at `.planning/REQUIREMENTS.md:957-958`:

> Until they exist, this document is enforced by attention alone, which is the condition that
> produced the previous version.

That is the phase's own artifact conceding that the phase's own criterion is unmet. The corpus was
rebuilt spec-first, which is real and valuable work; the *gate* was not built.
