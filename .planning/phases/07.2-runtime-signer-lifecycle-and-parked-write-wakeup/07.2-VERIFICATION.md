Builder signers seed one `Session`; `Fava` and `Publication` retain clones of
that same owner. Session revisions are wake signals only. Each publication
reloads its current unsigned event pubkey and compares the exact attachment
generation before cancelling or starting signer work. Completion admission
then checks the same attachment generation before the write store's existing
materialization/event/signature guards.
