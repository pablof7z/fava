# Phase 07.2 — Security

> Per-phase security contract: runtime signer trust boundaries, mitigations,
> and verification evidence.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Application signer → Session | Runtime attachment mutation | signer provider and author public key |
| Session revision → Publication | Coalesced attachment-change notification | revision and exact-key attachment generation |
| Signer provider → Publication | Potentially blocking or malformed completion | unsigned body, cancellation, signed event or typed error |
| Concurrent application mutations → Session | Simultaneous bounded map changes | add, replace, and remove requests |
| Retired signer → WriteStore | Late completion after replacement/removal | signed event or refusal from stale generation |
| Build graph → downstream consumers | Public crate and API availability | Cargo/Bazel dependencies and facade symbols |
