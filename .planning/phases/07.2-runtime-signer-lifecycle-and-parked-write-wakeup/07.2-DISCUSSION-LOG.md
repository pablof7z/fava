## Publication Wakeup

| Option | Description | Selected |
|--------|-------------|----------|
| Retry all parked writes on any signer change | Simple global restart with unrelated churn. | |
| Revision signal plus exact generation reload | Every loop wakes coalescibly but acts only when its exact pubkey attachment changed. | ✓ |

**User's choice:** Runtime signer availability must wake the relevant parked writes without changing protocol/write ownership.
**Notes:** Same-pubkey replacement requires an attachment generation beyond existing revision identity.
